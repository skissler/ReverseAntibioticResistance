## Output Conventions
- Write all mathematical/equation output to a separate HTML file: `notes/math_output.html` for easier reading. Do not inline heavy math in terminal output. Do not ever re-write `math_output.html`; instead, append new responses after existing ones. Each time responses are written to `math_output.html` on a new day, write a header with the date. Include both the prompt and the response, with the prompt in a quote block. 

## Workflow Preferences
- Err on the side of proposing changes rather than making them directly.
- For changes that affect key model assumptions or parameters, always present the proposed change and rationale first, wait for approval before implementing.
